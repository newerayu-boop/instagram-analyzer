# Промпт сборки базы знаний из расшифровок

Когда в папке есть `transcripts/` (и, если удалось, `telegram/`), откройте Claude Code
в `docs/experts/nikita-vels/` и вставьте промпт ниже. Либо закиньте папку `transcripts/`
в эту же сессию: базу соберу я.

---

```text
В папке transcripts/ лежат расшифровки YouTube-видео Никиты Велса за последние
6 месяцев (по одному .md на видео, во frontmatter есть дата и ссылка), в
telegram/ — посты его канала. Собери из них базу знаний в knowledge/.

Шаг 1 — конспект каждого видео: knowledge/videos/<тот же файл>.md
  - 5–10 главных тезисов его словами;
  - пошаговые инструкции (команды, настройки, порядок действий);
  - промпты и шаблоны, которые он диктует или показывает (дословно);
  - инструменты/модели/сервисы с его оценкой (плюсы, минусы, цена);
  - кейсы и цифры (только те, что он сам называет);
  - мнения и прогнозы; что он называет ошибками;
  - таймкоды, если есть главы.
  Делай субагентами пачками по 5 видео, чтобы не забить контекст.

Шаг 2 — тематические файлы (сводка по всем конспектам, с источниками
«[видео](ссылка), дата» у каждого пункта):
  knowledge/01-claude-code-basics.md      установка, первые шаги, CLAUDE.md, режимы
  knowledge/02-skills-mods-plugins.md     скиллы, моды, плагины, как писать свои
  knowledge/03-agents-teams-workflows.md  субагенты, Agent Teams, Workflows, MCP
  knowledge/04-vibe-coding-frameworks.md  Autopilot, Matt Pocock, его фреймворки
  knowledge/05-sites-design.md            сайты, Claude Design, «нейрослоп»
  knowledge/06-content-video.md           монтаж, контент-заводы, Reels, соцсети
  knowledge/07-models-costs.md            Opus/Fable/GPT-6/DeepSeek/Kimi, лимиты, экономия
  knowledge/08-other-tools.md             Codex, Cowork, Antigravity, OpenClaw, n8n
  knowledge/09-business-cases.md          кейсы внедрений, деньги, как продаёт AI-услуги
  knowledge/10-prompts-library.md         все промпты и шаблоны дословно
  knowledge/11-how-he-thinks.md           принципы, убеждения, частые фразы, стиль
  knowledge/12-faq.md                     30–50 вопросов новичка → ответ + видео
  knowledge/13-timeline.md                что когда менялось (что устарело и чем заменено)
Если тема из списка не встречается — не создавай файл. Если есть тема вне
списка — добавь файл.

Правила: ничего не додумывать; противоречия между видео — показать оба
мнения с датами, свежее считать актуальным; без воды.

Шаг 3 — обнови videos-catalog.md (даты публикации) и profile.md (стиль,
убеждения по факту расшифровок), допиши в AGENT.md список файлов базы.
```
