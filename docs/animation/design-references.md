# Визуальные референсы (design board)

> Референсы, присланные пользователем 2026-07-24. Разобраны по методологии
> **AI · WEB · METHOD**, этап 2 («Анализ референсов»): забираем не картинки, а
> решения — структуру, палитру, типографику и приёмы движения. Три разных
> премиум-направления: **dark luxury портфолио**, **инфобиз high-ticket лендинг**
> и **3D scroll-cinematic**.
>
> **Статус:** пользователю нравятся **все три** направления. Пока ничего не собираем —
> только копим референсы. **Board будет пополняться** (пользователь пришлёт ещё сайты) —
> каждый новый добавляем тем же разбором: палитра · типографика · структура · движение.

Общая нить всех трёх: **тёмная база + один металлический акцент** (синий / золото /
хром), **редакторская типографика с характером**, **одно фирменное движение на экран**,
**кинематографичная глубина** (свечение, свет-споты, частицы, тонированные тени).

## 1. Mariana Napolitani — Dark-luxury портфолио дизайнера

**Направление:** Dark luxury / premium personal portfolio.

**Палитра:** глубокий сине-чёрный фон (navy-black, ≈`#0A0E1A`), электрик-синий акцент с
градиентом (≈`#2E7FFF` → голубой) на фамилии, бело-серебристый на имени, холодные синие
свечения (glow). Один акцветовой акцент, строгая дисциплина.

**Типографика:** крупный редакторский **serif высокого контраста** для имени
(`MARIANA` серебром, `NAPOLITANI` синим градиентом); разряженный (letter-spacing)
uppercase **sans** для эйбрау и лейблов (`FEATURED PROJECTS`, `WHAT I DO`).

**Структура экранов (маршрут):**
- **HERO (split):** слева текст — `HELLO, I'M` → огромное имя → подзаголовок «I design
  digital experiences that inspire and perform» → буллеты специализации + гео → CTA
  `VIEW MY WORK →` и подпись от руки. Справа — портрет в **неоновом круглом ореоле**
  (светящееся кольцо за головой) на тёмном фоне. Это «фирменное» движение экрана.
- **FEATURED PROJECTS:** ряд из 3 карточек `01 LUXEY / 02 PULSE / 03 ELEVATE` с
  device-mockup'ами, тегами (WEB DESIGN / UI/UX / BRANDING), годом и `VIEW PROJECT →`.
- **WHAT I DO:** 4 стеклянные (glassmorphism) карточки услуг с line-иконками —
  Web Design, UI/UX, Branding, Prototyping.
- **Stats:** крупные цифры акцентом — `60+ / 30+ / 4+ / 100%` (табличные, «доказательства»).
- **CTA / контакт:** «LET'S CREATE SOMETHING EXTRAORDINARY», контакты (email, IG, сайт,
  гео) и **3D-хром логотип `N`** с бликами.

**Приёмы движения (как оживить):** свечение кольца (мягкий pulse/rotate), reveal карточек
каскадом по скроллу, hover-lift на карточках проектов, лёгкий parallax портрета/ореола,
хром-логотип с бегущим бликом. Всё на transform/opacity.

**Куда мапится:** методология → «Dark luxury» + анатомия (hero → proof/projects →
services → stats → CTA). Палитра/типографику можно взять из **ui-ux-pro-max** (dark-стили).

## 2. Игорь Рыбаков · X10 Academy — Инфобиз high-ticket лендинг

**Направление:** тёмный премиум-инфобиз (личный бренд, программа с высоким чеком).
⚠️ Реальная публичная персона — референс берём как **приём/структуру**, не копируем
контент 1:1.

**Палитра:** почти чёрный / графитовый фон, тёплый **крем/бежевый + шампань-золото**
(≈`#EAD9B0`) как акцент, мягкие тёплые **световые споты** (volumetric light).

**Типографика:** тяжёлый **сжатый гротеск, uppercase** для заголовков
(`ИГОРЬ РЫБАКОВ`, `ДЛЯ КОГО ДАННАЯ ПРОГРАММА`) — высокий, плотный; элегантный serif-ватермарк
`YAR` на фоне; чистый sans для тела.

**Структура экранов (маршрут доверия → заявка):**
- **Sticky CTA-пилюля** сверху: `Подать заявку`.
- **HERO (split):** слева портрет с **верифицированным бейджем IG** `@rybakov_igor`;
  справа — **стек регалий** маркерами: топ-100 Forbes Россия, совладелец «Технониколь»,
  автор 7 книг, филантроп/фонд, самый успешный бизнес-блогер СНГ. Классическое
  «снятие сомнения сразу» (доверие).
- **Пул-цитата** в рамке: «Это ваш шанс получить опережающий доступ к инструментам…».
- **«ДЛЯ КОГО ДАННАЯ ПРОГРАММА»:** театральные **споты** + **3D-кейс (чемодан) с золотыми
  слитками** и лого `X10 ACADEMY`, вокруг — 6 карточек-сегментов аудитории (хочет жить
  мощно; доступ к власти/влиянию; выйти из операционки; передавать опыт; видит потенциал;
  усиливающее окружение).
- **Финальный CTA:** `ПОЛУЧИТЬ ЖИЗНЬ X10` (большая кнопка-пилюля).

**Приёмы движения:** драматичное появление регалий по одной, «дыхание» спотов,
3D-чемодан с бликом на слитках, hover на карточках-сегментах. Сдержанно, «дорого».

**Куда мапится:** методология → доверие/регалии, «кому это», high-ticket CTA. В этой
среде — родственные скиллы **`infobiz-launch`** (воронка/оффер/прогрев) и
**`umid-landing-framework`** (сборка). Тексты на узбекский — через **`uzbek-expert-voice`**.

## 3. AURUM & NOIR — 3D scroll-cinematic (видео-референс)

**Что это:** 16-сек демо **3D scroll-cinematic** сайта люксовых часов «AURUM & NOIR ·
Edition I — Eclipse». Скролл управляет фотореалистичной **3D-моделью часов**: она
вращается/приближается/«раскрывается», показывая механизм (турбийон, шестерни), а поверх —
синхронные кинематографичные надписи. Сохранённые кадры (обрезаны от плеера):
[`references/aurum-noir-3d-scroll-1_5s.jpg`](references/aurum-noir-3d-scroll-1_5s.jpg),
[`references/aurum-noir-3d-scroll-4_5s.jpg`](references/aurum-noir-3d-scroll-4_5s.jpg),
[`references/aurum-noir-3d-scroll-10_5s.jpg`](references/aurum-noir-3d-scroll-10_5s.jpg).

**Палитра:** чёрный + золото, кинематографично; боке-частицы, глубокие тонированные тени.

**Типографика:** мелкие разряженные uppercase лейблы секций слева-сверху
(`03 — ENGINEERING`, `AURUM & NOIR`), крупные serif-числа как «призрачный» водяной знак
(`217`, `42mm`), центрированные фразы-акценты (`The Tourbillon breathes.`).

**Приём (как воспроизвести):**
- Стек: **Three.js** (есть в 22 стеках ui-ux-pro-max) или **React Three Fiber + drei**
  (`<ScrollControls>`, `useScroll`), модель `GLTF/GLB`.
- Скролл-движок: **GSAP ScrollTrigger** (pin + scrub) или **Lenis + прогресс скролла** →
  прогонять кадр анимации модели / позицию камеры по прогрессу секции.
- Слои: пин-секция с 3D по центру → интерполяция rotation/zoom/«explode» модели →
  fade-in текстовых оверлеев на ключевых кадрах (как `animateMultiElementReveal` из forn.dk).
- Производительность: тяжёлые ассеты — сжать GLB (Draco), ленивая загрузка, `fetchpriority`
  на hero; **fallback на `prefers-reduced-motion`** = статичные hero-кадры без скролл-скраба.

**Контекст:** демонстрировал автор-портфолио «AI BUILDER — CLAUDE CODE» (секции
`PROOF OF WORK`, проекты `CITEVUE`, `SCROLL-CINEMATIC` — «движок вирусного 3D-скролла,
вы скроллите его прямо сейчас», `199 SKILLS`) — т.е. подобное собирается **в Claude Code**.

**Куда мапится:** методология → «Scrollytelling» + этап 8 «Движение». На **motionsites.ai**
это категории **3D animations** и **scroll-based interactions** (фильтр Free) — оттуда
берём готовые промпты под такой эффект.

## Как использовать этот board

1. Под конкретный проект выбери **одно** направление (dark luxury / инфобиз / scroll-3D),
   а немешай всё.
2. Забери **структуру и приём**, наполни **реальными данными из брифа** (этап 1), сгенерируй
   **оригинальный визуал под бренд** (этап 6) — не копируй чужой контент.
3. Палитра/шрифты — из **ui-ux-pro-max**; движение — из
   [`../animation-ui-ux-resources.md`](../animation-ui-ux-resources.md) (раздел 7) и
   готовых `scroll-reveal.js/.css`; промпты анимации — с **motionsites.ai**.
4. Прогони по чек-листу «дорого, а не шаблон» в конце мастер-справочника.
