# «Джарвис» для предпринимателя — рабочие шаблоны

Проверено 2026-08-26. Задача: найти шаблоны ИИ-ассистента, которые ставятся
своими руками, покрывают **маркетинг · операционку · продажи · финансы**
и **не ломаются**.

---

## Главный вывод

Одного шаблона «поставил — и Джарвис работает вечно» не существует. Есть
**два уровня**, и они принципиально разные по надёжности. Путать их — главная
ошибка, из-за которой всё «ломается».

| | Уровень 1 — плагины Claude | Уровень 2 — n8n / Make |
|---|---|---|
| Что это | Готовые бизнес-сценарии внутри Claude | Автоматизации, которые срабатывают сами |
| Кто чинит | Anthropic, обновления приходят сами | Ты |
| Сервер | Нет | Есть (или облако за деньги) |
| Токены/доступы протухают | Нет | Да, регулярно |
| Ставится за | 5 минут, тумблером | От часа до нескольких дней |
| Ломается | Практически никогда | Регулярно |
| Умеет работать без тебя 24/7 | **Нет** | **Да** |

**Правило внедрения: начинать с Уровня 1. Переходить на Уровень 2 только там,
где реально нужно «само срабатывает по событию, пока я сплю».**

---

## Уровень 1 — то, что не ломается

Официальные плагины Anthropic. Ставятся тумблером, без кода, без сервера.
Внутри — готовые команды под каждую из четырёх областей.

### Что ставить под наши четыре задачи

| Область | Плагины | Ключевые команды |
|---|---|---|
| **Финансы** | `finance` + `small-business` | `/close-month`, `/plan-payroll`, `/cash-flow-snapshot`, `/margin-analyzer`, `/tax-prep`, `/invoice-chase`, `/price-check` |
| **Продажи** | `sales` + `small-business` | `/lead-triage`, `/call-prep`, `/call-summary`, `/pipeline-review`, `/draft-outreach`, `/forecast`, `/call-list`, `/sales-brief` |
| **Маркетинг** | `marketing` + `small-business` | `/run-campaign`, `/campaign-plan`, `/draft-content`, `/brand-review`, `/competitive-brief`, `/seo-audit`, `/content-strategy`, `/canva-creator` |
| **Операционка** | `operations` + `small-business` | `/process-doc`, `/runbook`, `/status-report`, `/vendor-review`, `/capacity-plan`, `/monday-brief`, `/friday-brief`, `/business-pulse` |

`small-business` — самый ценный: 31 навык, закрывает все четыре области сразу
плюс HR и клиентский сервис. Если ставить только один — ставить его.

### Как установить

1. Claude **десктоп-приложение** → Cowork
2. Слева **Customize** → раздел **Plugins** → кнопка **+**
3. Найти нужный плагин в каталоге → **Install**
4. Первым делом запустить **`/smb-onboard`** — это первичная настройка
5. Подключить те сервисы, которыми реально пользуешься

**Требования:** тариф **Pro, Max, Team или Enterprise**. На Free-плане плагины
не работают.

**Безопасность:** любой шаг, который отправляет, публикует или платит,
требует твоего подтверждения. Автоматически деньги никуда не уйдут.

---

## Важно: что из этого работает в Узбекистане

Родные коннекторы плагинов — западные: QuickBooks, PayPal, HubSpot, DocuSign,
Stripe, Square. У наших предпринимателей их обычно **нет**.

**Но это не блокер.** Сценарии спроектированы «degrade gracefully» — работают
и без подключённых сервисов, на выгруженных файлах.

Рабочая связка для узбекского бизнеса:

| Что нужно сценарию | Чем заменяем у нас |
|---|---|
| QuickBooks (учёт) | Google Sheets / Excel — выгрузка или ручная таблица |
| HubSpot (CRM) | Выгрузка из amoCRM / Bitrix24 в CSV |
| PayPal / Stripe | Выписка из Payme / Click / банка в Excel |
| Gmail, Google Calendar, Google Drive | Работают как есть — есть у всех |
| Canva | Работает как есть |

**Честно ученикам:** прямого автоподключения к Payme, Click и 1С нет и не
обещаем. Формула для нас — **«данные руками или выгрузкой → сценарий делает
работу»**. Это всё равно экономит часы, но это не «оно само ходит в мой банк».

## Уровень 2 — n8n, и почему он ломается

n8n нужен ровно для одного: **сработать самому по событию или расписанию,
без тебя**. Пришла заявка → занеси в таблицу → напиши в Telegram. Плагины так
не умеют — их надо позвать.

### Почему готовые шаблоны не заводятся

Большинство шаблонов в интернете писались под **n8n v0.x**, а сейчас в ходу
**v1.x–v2.x**. Половина нод переименована, половина методов авторизации
изменилась. Плюс шаблон всегда собран под **чужие доступы, чужие названия
полей и чужие данные**. Это не «кривой шаблон» — это норма жанра.

### Где брать, по убыванию надёжности

1. **[n8n.io/workflows](https://n8n.io/workflows/)** — официальная библиотека,
   11 700+ шаблонов, фильтр по интеграциям. Начинать здесь.
2. **[n8n.io/creators/n8n-team](https://n8n.io/creators/n8n-team/)** — шаблоны
   самой команды n8n. Самые надёжные из всех.
3. **[n8n.io/creators](https://n8n.io/creators/)** — верифицированные авторы.
4. **[Make.com Templates](https://www.make.com/en/templates)** — 1 000+ готовых
   сценариев, фильтр по Sales / Marketing / Operations / Finance. Ломается
   реже n8n: коннекторы обслуживает сам Make. Минус — оплата за операции
   (бесплатно 1 000 операций в месяц).
5. GitHub-сборники вроде `awesome-n8n-templates` — **в последнюю очередь**.
   Там больше всего мёртвого кода.

### Готовые «Джарвисы» на n8n (Telegram-ассистенты)

- [Jarvis: productivity AI agent](https://n8n.io/workflows/8500-jarvis-productivity-ai-agent-for-tasks-calendar-email-and-expense-using-mcps/) —
  задачи, календарь, почта, расходы. Нужны: Telegram Bot API + OpenAI API
  (обязательно), Gmail / Calendar / Contacts / ElevenLabs (опционально).
- [Angie — personal AI assistant](https://n8n.io/workflows/2462-angie-personal-ai-assistant-with-telegram-voice-and-text/) — голос и текст в Telegram.
- [AI assistant с памятью и задачами](https://n8n.io/workflows/8837-ai-powered-personal-assistant-for-telegram-with-memory-and-task-management/) — помнит контекст.

### Чек-лист «шаблон не сломается»

Порядок обязательный. Пропуск любого шага = поломка.

1. **Прочитать целиком, не запуская.** Понять, что делает каждая нода.
2. **Заменить все доступы** на свои — до единого.
3. **Сопоставить названия полей** со своими реальными данными.
4. **Пересобрать триггер** под свой сценарий.
5. **Тестировать по одной ноде**, а не весь сценарий разом.
6. **Добавить обработку ошибок** — в шаблонах её почти никогда нет.

**Отдельное правило:** брать **n8n Cloud**, а не self-hosted на своём VPS.
Иначе к поломкам шаблонов добавятся поломки сервера, и разбираться придётся
в двух местах сразу.

## Порядок внедрения

Для себя и потом для учеников — один и тот же.

| Когда | Что делаем |
|---|---|
| **Неделя 1** | Ставим плагины, запускаем `/smb-onboard`, подключаем Google. Осваиваем по одной команде в день. |
| **Неделя 2** | `/monday-brief` каждый понедельник, `/friday-brief` в пятницу. Цель — привычка, не объём. |
| **Неделя 3** | Добираем по одной области: финансы → продажи → маркетинг → операционка. |
| **Неделя 4** | Только теперь n8n. И только 1–2 сценария, которые реально болят. |

---

## Чего не делать

- **Не тащить 20 n8n-шаблонов сразу.** Сломается всё и одновременно, причину
  не найдёшь.
- **Не ставить self-hosted n8n на старте.**
- **Не обещать «поставил и забыл» про n8n.** Про плагины — можно, про n8n —
  нельзя.
- **Не давать ученикам сценарии с доступом к деньгам** без ручного
  подтверждения на каждом шаге.
- **Не начинать с Уровня 2.** Это главная причина, по которой у людей
  «Джарвис» разваливается на второй неделе.
