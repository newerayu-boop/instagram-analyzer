  • Suhbat uzayganda tizim ChatGPT chegarasidan oldin mazmunni avtomatik qisqartiradi — shunda ish to'xtamaydi.
  • «Streaming fallback» o'chirilgan — bu bitta buyruq ikki marta bajarilib qolishining oldini oladi.

·Bitta so'z bilan (alias)

Har safar uzun blokni yozmaslik uchun ikkita qisqa nom yaratamiz. Quyidagi ikki qatorni ~/.zshrc faylining oxiriga qo'shing:

~/.zshrc
alias claudex-serve='claude-code-proxy serve'
alias claudex="ANTHROPIC_BASE_URL='http://127.0.0.1:18765' ANTHROPIC_AUTH_TOKEN='unused' ANTHROPIC_MODEL='gpt-5.6-sol[1m]' ANTHROPIC_SMALL_FAST_MODEL='gpt-5.6-luna[1m]' CLAUDE_CODE_AUTO_COMPACT_WINDOW='272000' CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC='1' CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK='1' claude"

Keyin faylni qayta o'qiting:

Terminal
source ~/.zshrc

Endi hammasi oson:

  • claudex-serve — proksini ishga tushiradi (1-terminal).
  • claudex — Sol bilan seansni ochadi (2-terminal).
  • claude — oddiy Claude, hech narsa o'zgarmaydi. Har doim avvalgidek ishlaydi.

·Halol gap

Buni ochiq aytish kerak:

  • Bunga ikkita obuna kerak: Anthropic (Claude) va ChatGPT. Ya'ni ikki to'lov va ikki limit.
  • Bu usul ChatGPT obunangizni norasmiy mahalliy proksi orqali o'tkazadi. Bu shaxsiy foydalanish uchun.
  • Kompaniya uchun bunday qilmang — kompaniyada rasmiy, to'lov qilinadigan OpenAI API orqali ulaning.
  • Agar Claude Code o'zi qurayotgan hamma narsangizni bemalol chiqarib bersa, bu qo'shimcha sizga umuman kerak bo'lmasligi mumkin.

·Rasmiy plugin yo'li (bonus)

Agar sizga Sol faqat tekshiruvchi sifatida kerak bo'lsa, uni proksisiz, rasmiy plugin orqali ham ulash mumkin. Claude Code ichida quyidagi buyruqlarni ketma-ket bajaring:
