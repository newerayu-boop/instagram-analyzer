# Дашборд задач команды — `/dashboard`

Живая система вместо статичного ганта: **идея → инбокс → триаж → задача → загрузка команды**.

Вкладки:

- **Доска** — канбан: К выполнению / В работе / Ждём 🏀 / Сделано.
- **Сегодня** — встречи дня, просрочка, задачи по людям; кнопки «✓ сделано» и «→ на завтра».
- **Идеи** — инбокс идей (с дашборда и из Telegram) и триаж: «берём сейчас / после запуска / нет».
- **Мяч** — от кого ждём подтверждения и сколько дней; «мяч вернулся» возвращает задачу в работу.
- **Гант** — картина по срокам на 2 недели, с лентой встреч.
- **Загрузка** — сколько открыто / сегодня / просрочено / «мячей» у каждого.

Данные — Supabase (проект `ai-strateg-klub`), таблицы с префиксом `dash_*`.
Серверная часть: `api/tasks.js` (данные), `api/tasks-digest.js` (сводки), `api/tasks-inbox.js` (идеи из Telegram).

## Что работает сразу

Сам дашборд — без всякой настройки, сразу после деплоя. На боевом домене появится после
мёрджа ветки в `main` (до этого Vercel даёт превью-ссылку ветки). При первом входе человек
выбирает своё имя — им подписываются все отметки.

Telegram-функции (сводки и приём идей) включаются переменными окружения — см. ниже.
Пока их нет, дашборд просто работает без бота.

## Telegram-бот: сводки утром и вечером

Бот **отдельный** от лендингового (который присылает заявки).

1. В Telegram: **@BotFather** → `/newbot` → имя и юзернейм → скопировать **токен**.
2. Добавить бота в групповой чат команды.
3. Узнать id чата: написать что-нибудь в чат, открыть
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`
   (у групп он отрицательный, вида `-100…`). Если ответ пустой — выключить приватность:
   @BotFather → `/setprivacy` → **Disable**, и написать в чате `/start@ИмяБота`.
4. Vercel → Settings → **Environment Variables**:

   | Переменная | Что это | Обязательно |
   |---|---|---|
   | `TASKS_BOT_TOKEN` | токен бота из шага 1 | да (для бота) |
   | `TASKS_CHAT_ID` | id чата из шага 3 | да (для бота) |
   | `CRON_SECRET` | случайная строка — закрывает ручной вызов сводки | нет |
   | `IDEAS_CHAT_ID` | id отдельного чата, где каждое сообщение = идея | нет |
   | `TG_WEBHOOK_SECRET` | случайная строка для вебхука идей (шаг ниже) | нет |

5. **Redeploy** (переменные подхватываются только новым деплоем).
6. Проверка без отправки: `https://<домен>/api/tasks-digest?mode=morning&dry=1` —
   вернёт текст сводки. Без `dry=1` — реально отправит в чат.

**Расписание** (кроны Vercel в `vercel.json`):

- ☀️ утро — 09:00 по Ташкенту: встречи, задачи по людям, просрочка, «у кого мяч»,
  инбокс идей, призыв дополнить свои задачи;
- 🌙 вечер — 19:00: что сделано, что осталось, призыв отметить/перенести и составить
  план на завтра (10 минут).

На тарифе Vercel Hobby крон срабатывает «в течение часа» от назначенного времени — это нормально.

## Идеи из Telegram («идея за 30 секунд»)

Чтобы идеи падали в инбокс прямо из Telegram, один раз включите вебхук
(подставьте токен, домен и придуманную случайную строку):

```
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<домен>/api/tasks-inbox&secret_token=<СЛУЧАЙНАЯ_СТРОКА>"
```

и добавьте в Vercel `TG_WEBHOOK_SECRET` = та же строка (+ Redeploy).

Что считается идеей:

- **личное сообщение боту** — любой текст целиком;
- сообщение в **чате идей** (если задан `IDEAS_CHAT_ID`) — любой текст целиком;
- в **любом другом чате** — только по префиксу: `идея: …`, `idea: …`, `#идея …`
  (для этого у бота должна быть выключена приватность — `/setprivacy` → Disable).

Бот отвечает «✅ Идея в инбоксе». Разбор — раз в день на триаже (вкладка «Идеи»).
Проверить вебхук: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`.

## Коды ошибок API

| `error` | Что значит |
|---|---|
| `not_configured` | не заданы `TASKS_BOT_TOKEN`/`TASKS_CHAT_ID` — сводка не отправлена |
| `unauthorized` | не совпал `CRON_SECRET` или `TG_WEBHOOK_SECRET` |
| `upstream_failed` | Supabase не ответил / отклонил запрос (детали в логах Vercel) |
| `telegram_failed` | Telegram не принял сообщение (чаще всего неверный chat_id) |
| `missing_name` | в запросе нет имени `by` — фронт всегда его шлёт |
| `invalid_fields` | не прошла валидация полей (даты, статусы, обязательные) |

## Безопасность — прочитать один раз

Дашборд **осознанно открыт**: без пароля, по прямой ссылке. Anon-ключ Supabase публичен
по дизайну и вшит константой в API-файлы; таблицы `dash_*` открыты политиками RLS.
Это значит: любой, кто узнает адрес, сможет читать и менять задачи. Для внутреннего
инструмента команды это принятый компромисс в пользу нулевого трения.

Захотите закрыть — делается без переделки интерфейса (весь трафик уже идёт через `/api/tasks`):

1. Добавить env `DASH_KEY` и проверку ключа в `api/tasks.js` — по образцу `LEADS_KEY`
   в `api/leads.js` (страница `/leads` так уже работает).
2. В Supabase заменить открытые политики `dash_*_open` на запрет для `anon`,
   а в API перейти на `service_role`-ключ из env.
3. Если ротировали anon-ключ — поменять константу `SUPABASE_ANON` в трёх файлах:
   `api/tasks.js`, `api/tasks-digest.js`, `api/tasks-inbox.js`.

## Supabase free tier

Бесплатный проект засыпает без обращений ~неделю. Кроны сводок ходят в базу дважды в день,
так что при включённом боте проект не заснёт. Если всё же уснул (в панели Supabase статус
Paused) — нажать **Restore**, данные не теряются.
