# Запуск Jarvis по шагам

От нуля до работающего бота в Telegram. Ничего не нужно знать заранее.
Считай, что это рецепт: делай по порядку, не перепрыгивай.

**Время:** 40–60 минут в первый раз, 10 минут во второй.
**Деньги:** Vercel и Supabase — бесплатно на старте. Claude API —
примерно $5–15 в месяц на одного активного пользователя.

---

## Что нужно завести заранее

| Что | Где | Зачем |
|-----|-----|-------|
| Telegram | уже есть | там живёт бот |
| Аккаунт Anthropic | console.anthropic.com | мозг |
| Аккаунт Vercel | vercel.com | там крутится код |
| Аккаунт Supabase | supabase.com | память |
| GitHub | github.com | код едет на Vercel отсюда |

---

## Шаг 1. Создать бота в Telegram

1. Открой в Telegram [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Введи **имя** — как будет подписан бот: `Jarvis — bizness yordamchi`
4. Введи **username** — обязательно заканчивается на `bot`:
   `my_jarvis_bot`
5. BotFather пришлёт токен вида
   `7123456789:AAH8xY_qWeRtYuIoPaSdFgHjKlZxCvBnM`

**Этот токен — пароль от бота. Никому не показывай и не клади в код.**
Если случайно показал — `/revoke` у BotFather, и токен станет новым.

Пока ты у BotFather, сделай бота приятнее:

```
/setdescription   — Bizness yordamchingiz: marketing, moliya, operatsiya, savdo
/setabouttext     — 4 bo'lim bitta chatda
/setcommands
```
и вставь список команд:
```
start - Boshlash
help - Nima qila olaman
profil - Biznesim haqida nima bilasan
reset - Suhbatni unut
id - Mening telegram id
```

---

## Шаг 2. Получить ключ Claude

1. Зайди на [console.anthropic.com](https://console.anthropic.com)
2. **Billing** → пополни баланс. Начни с $10 — этого хватит надолго
   на тесты.
3. **API Keys** → *Create Key* → назови `jarvis` → скопируй.
   Ключ показывают **один раз**. Потерял — создавай новый.

Сразу поставь предохранитель: **Limits** → месячный лимит трат.
Поставь сумму, которую не жалко. Это единственная защита от ситуации
«что-то зациклилось ночью».

---

## Шаг 3. Создать память

1. [supabase.com](https://supabase.com) → *New project*
2. Имя `jarvis`, регион — ближайший (Frankfurt для Узбекистана),
   придумай пароль базы и сохрани его
3. Подожди 2 минуты, пока проект поднимется
4. Слева **SQL Editor** → *New query*
5. Открой файл `lib/jarvis/schema.sql` из этого проекта, скопируй
   **целиком** и вставь → **Run**
6. Должно написать `Success`. Слева в **Table Editor** появятся девять
   таблиц `jarvis_*`
7. **Project Settings → API**, скопируй:
   - `Project URL` → это `SUPABASE_URL`
   - ключ **service_role** (`secret`) → это `SUPABASE_SERVICE_KEY`

> `service_role` — ключ с полным доступом. Он живёт **только** на сервере,
> в переменных Vercel. Никогда не вставляй его в сайт, в HTML или в чат.

---

## Шаг 4. Придумать секрет вебхука

Это пароль, которым Telegram подписывает каждый запрос к твоему сайту.
Сгенерируй случайную строку — например, в терминале:

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```

Скопируй результат. Это `TELEGRAM_WEBHOOK_SECRET`.

---

## Шаг 5. Положить всё в Vercel

Открой проект на Vercel → **Settings → Environment Variables**.
Добавь по одной (Environment: *Production*, *Preview*, *Development* — все три):

| Имя | Значение | Обязательно |
|-----|----------|-------------|
| `ANTHROPIC_API_KEY` | ключ из шага 2 | да |
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 | да |
| `TELEGRAM_WEBHOOK_SECRET` | секрет из шага 4 | да |
| `SUPABASE_URL` | из шага 3 | для памяти |
| `SUPABASE_SERVICE_KEY` | из шага 3 | для памяти |
| `OPENAI_API_KEY` | ключ OpenAI | только для голосовых |
| `JARVIS_ALLOWED_IDS` | пока пусто | закроем на шаге 8 |
| `JARVIS_CURRENCY` | `UZS` | нет |
| `JARVIS_TZ` | `Asia/Tashkent` | нет |

**Важно:** Vercel подхватывает новые переменные только при следующем
деплое. Добавил переменную — сделай **Redeploy**.

---

## Шаг 6. Задеплоить

Если код уже в GitHub и связан с Vercel — просто запушь ветку,
деплой поедет сам. Иначе: **Add New → Project → Import** из GitHub.

Когда деплой позеленел, открой в браузере:

```
https://твой-проект.vercel.app/api/jarvis
```

Должен ответить JSON примерно такой:

```json
{"ok":true,"service":"jarvis","brain":true,"telegram":true,
 "memory":true,"secret":true,"departments":["marketing","finance","ops","sales","general"]}
```

**Читай его как чек-лист:**
- `brain: false` → не подхватился `ANTHROPIC_API_KEY`
- `telegram: false` → нет `TELEGRAM_BOT_TOKEN`
- `memory: false` → нет ключей Supabase (бот заработает, но без памяти)
- `secret: false` → нет `TELEGRAM_WEBHOOK_SECRET`

Если что-то `false` — вернись в Settings, проверь имя переменной
(регистр важен!) и сделай Redeploy.

---

## Шаг 7. Соединить бота с сайтом

Telegram пока не знает, куда слать сообщения. Скажи ему:

```bash
export TELEGRAM_BOT_TOKEN="7123456789:AAH..."
export TELEGRAM_WEBHOOK_SECRET="тот-самый-секрет"
node tools/jarvis-setup.js https://твой-проект.vercel.app
```

Скрипт напечатает имя бота и подтвердит установку.

Теперь открой бота в Telegram и напиши `/start`. Он должен ответить.

**Не ответил?** Проверь:

```bash
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getWebhookInfo"
```

Смотри поле `last_error_message` — там написана настоящая причина.
Разбор частых ошибок — в конце документа.

---

## Шаг 8. Закрыть бота от посторонних

Пока бот открыт всем, кто узнает его имя. Закрой:

1. Напиши боту `/id` — он ответит твой telegram id
2. В Vercel добавь `JARVIS_ALLOWED_IDS` = этот id
3. Несколько человек — через запятую: `111111,222222,333333`
4. Redeploy

Теперь чужие получат «Доступ закрыт».

---

## Шаг 9. Обучить Jarvis своему бизнесу

Свежий Jarvis умный, но ничего не знает про тебя. Первый разговор —
это заполнение анкеты. Напиши ему подряд:

```
Меня зовут Азиз. У меня магазин цветов в Ташкенте, работаю 2 года.
Средний чек 250 тысяч сум. В команде я и два продавца.
Клиенты приходят из инстаграма и с сарафана.
Главная проблема — заявок много, а покупают мало.
Цель на этот год — выйти на 50 млн выручки в месяц.
```

Jarvis сам разложит это на факты и запомнит. Проверь: `/profil`.

С этого момента каждый его ответ будет про **твой** бизнес,
а не про «бизнес вообще».

---

## Шаг 10. Проверить все четыре отдела

Напиши по одному сообщению на каждый отдел:

| Пишешь | Ждёшь |
|--------|-------|
| `потратил 300 тысяч на таргет` | 💰 Финансы, записал расход |
| `придумай 3 идеи для рилс` | 📣 Маркетинг, идеи с хуками |
| `клиент говорит дорого` | 🤝 Продажи, готовый ответ |
| `как передать заказы продавцу` | ⚙️ Операционка, инструкция |
| `сколько я потратил в этом месяце` | 💰 Финансы, реальная цифра из базы |

Последний вопрос — самая важная проверка. Если Jarvis назвал сумму,
которую ты записывал раньше, — **связка модель↔база работает**.
Если он «примерно прикинул» — значит инструмент не вызвался, смотри
логи Vercel.

## Проверка перед тем, как показывать людям

- [ ] `/api/jarvis` в браузере отвечает, всё `true`
- [ ] `/start` работает
- [ ] Все четыре отдела отвечают своей темой
- [ ] `/profil` показывает факты про бизнес
- [ ] Цифры в ответах совпадают с тем, что записано
- [ ] `JARVIS_ALLOWED_IDS` заполнен
- [ ] В Anthropic Console стоит месячный лимит трат
- [ ] Голосовое сообщение распознаётся (если нужен голос)
- [ ] Написал два сообщения подряд — второй ответ учитывает первый

## Когда что-то не работает

| Симптом | Настоящая причина | Что делать |
|---------|-------------------|------------|
| Бот молчит на всё | Вебхук не установлен или адрес неверный | `getWebhookInfo`, посмотреть `url` и `last_error_message` |
| «unauthorized» в логах | Секрет в Vercel и в `setWebhook` разные | Переустановить вебхук тем же секретом |
| Отвечает, но всё забывает | Нет ключей Supabase, память выключена | Проверить `memory:true` на `/api/jarvis` |
| Отвечает дважды | Дедупликация не работает — нет таблицы `jarvis_updates` | Прогнать `schema.sql` заново |
| Долго думает, потом ошибка | Функция не уложилась в таймаут | Понизить `JARVIS_EFFORT` до `low` или поднять лимит времени функции в Vercel |
| «Ассистент не подключён к мозгу» | Неверный `ANTHROPIC_API_KEY` | Пересоздать ключ, Redeploy |
| Придумывает цифры | Инструмент не вызывается | Проверить, что отдел определён верно; усилить фразу про инструменты в промпте |
| Счёт растёт быстро | Нет лимита и белого списка | Шаг 8 + лимит в консоли Anthropic |

**Где смотреть логи:** Vercel → проект → **Logs** → фильтр по `/api/jarvis`.
Все наши сообщения помечены `[jarvis]`.

## Проверка без Telegram

Пока настраиваешь — можно проверять из терминала, не трогая бота:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
node tools/jarvis-test.js "клиент говорит дорого, что ответить"
```

Скрипт покажет: какой отдел выбран, сколько шагов с инструментами,
сколько токенов ушло и сам ответ. Это самый быстрый способ
дорабатывать промпты — секунды вместо минут.
