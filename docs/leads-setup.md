# Куда попадают заявки с лендинга

Форма на `/masterclass` отправляет данные на `/api/lead`. Оттуда заявка уходит
в два независимых места:

1. **Google-таблица** — основное хранилище;
2. **Telegram** — мгновенное уведомление (необязательно).

Заявка считается принятой, если сработал **хотя бы один** канал. Если Telegram
не настроен или временно недоступен, запись в таблицу всё равно произойдёт, и
клиент увидит подтверждение.

После успешной отправки клиент автоматически переходит в Telegram менеджера:
<https://t.me/Yusufbaymanager>

## 1. Google-таблица

Таблица **«Hyatt Regancy 2»**:
<https://docs.google.com/spreadsheets/d/1lcWSTy4Xsp609YUohGBJcYf0-CJSn--k1ZLSUPrW3e4/edit>

Писать в таблицу напрямую сайт не может — нужен посредник. Им служит Google
Apps Script, который живёт внутри самой таблицы. Ключи Google при этом никуда
не передаются: скрипт работает от вашего имени и внутри вашего аккаунта.

### Шаги

1. Откройте таблицу → меню **Расширения** → **Apps Script**.
2. Удалите то, что там есть, и вставьте целиком код из
   [`tools/sheets-webhook.gs`](../tools/sheets-webhook.gs).
3. Сохраните (значок дискеты).
4. Нажмите **Начать развёртывание** → **Новое развёртывание**.
5. Шестерёнка рядом с «Тип» → выберите **Веб-приложение**.
6. Заполните:
   - **Описание** — любое, например `Заявки с сайта`
   - **Запуск от имени** — `Я` (ваш аккаунт)
   - **У кого есть доступ** — **`Все`**

   Последний пункт обязателен: сайт обращается к скрипту без входа в Google.
   Знать адрес скрипта посторонние не могут, а сам скрипт умеет только
   дописывать строки.
7. **Развернуть** → Google попросит разрешения → **Разрешить**.
   Если появится «Приложение не проверено» → «Дополнительные настройки» →
   «Перейти к проекту».
8. Скопируйте **URL веб-приложения** — длинная ссылка, оканчивающаяся на `/exec`.

### Проверка

Откройте скопированный URL в браузере. Должно появиться:

```json
{"ok":true,"hint":"Мост работает. Заявки принимаются методом POST."}
```

Если видите это — мост жив.

### Подключение к сайту

В Vercel → проект `suniyintellect-mk` → **Settings** → **Environment
Variables** → добавьте:

| Имя | Значение |
|---|---|
| `SHEETS_WEBHOOK_URL` | скопированный URL, оканчивающийся на `/exec` |

Затем **Deployments** → последний → ⋯ → **Redeploy**. Без пересборки новые
переменные не подхватятся.

### Что появится в таблице

Лист **«Arizalar»** создастся сам при первой заявке:

| Sana va vaqt | Ism | Telefon | Soha | Narx | Til | Manba | Holat |
|---|---|---|---|---|---|---|---|
| 29.07.2026 14:32 | Aziz Karimov | +998 90 123 45 67 | marketing | 497 000 soʻm | UZ | masterclass | Yangi |

Время — ташкентское. Телефон записывается как текст, иначе таблица съедает `+`.
Колонку «Статус» можно вести вручную.

### Если заявки не приходят, а скрипт отвечает 401

Значит при развёртывании доступ выставлен не «Все». Проверить и починить:

1. Таблица → **Расширения** → **Apps Script**
2. **Развернуть** → **Управление развёртываниями**
3. Карандаш ✏️ у активного развёртывания
4. **«У кого есть доступ»** → **Все**
5. **Развернуть**

Проверить можно, открыв URL скрипта в браузере: должен вернуться JSON
`{"ok":true,...}`, а не страница входа Google.

## 2. Telegram (необязательно)

Нужен, если хотите получать заявки мгновенно в чат.

| Имя | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather → `/mybots` → ваш бот → API Token |
| `TELEGRAM_CHAT_ID` | напишите боту, откройте `api.telegram.org/bot<ТОКЕН>/getUpdates`, возьмите `chat.id` |

Добавляются туда же, в Environment Variables, и так же требуют Redeploy.

## Как понять, что что-то не так

Откройте в браузере `https://<ваш-домен>/api/lead` — вернётся
`{"ok":false,"error":"method_not_allowed"}`. Это нормально: функция принимает
только POST, а браузер шлёт GET. Главное — что она отвечает.

Ответы функции на заявку:

| Ответ | Что значит |
|---|---|
| `{"ok":true,"delivered":["sheets"]}` | записано в таблицу |
| `{"ok":true,"delivered":["sheets","telegram"]}` | записано и отправлено в чат |
| `{"ok":false,"error":"not_configured"}` | не задана ни одна переменная |
| `{"ok":false,"error":"delivery_failed"}` | переменные есть, но оба канала не ответили |
| `{"ok":false,"error":"missing_fields"}` | пустое имя или номер короче 7 цифр |

Подробности отказов пишутся в логи функции: Vercel → проект → **Logs**.
