# Транскрибация узбекского видео — с таймкодами и собеседниками

Готовый скрипт, который берёт **узбекскую модель** `islomov/rubaistt_v2_medium`
(ту же, что внутри проекта [uzbek-dictation](https://github.com/MuhammadMirrr/uzbek-dictation))
и превращает твоё видео в текст:

- ⏱️ **таймкоды** в формате `ЧЧ:ММ:СС`
- 🗣️ **собеседники** — «Спикер 1», «Спикер 2»… (потом можно вписать реальные имена)
- 📄 два файла на выходе: **`.txt`** и **`.srt`** (субтитры)

> **Почему это надо делать у себя на компьютере?**
> Видео лежит локально в твоей папке Telegram Desktop. У ассистента в облаке
> доступа к твоим файлам нет, поэтому скрипт запускается на твоём ПК.

---

## Инструкция для Windows (по шагам)

### Шаг 1. Установи Python
1. Зайди на https://www.python.org/downloads/ и скачай **Python 3.10 или новее**.
2. При установке **обязательно поставь галочку** «Add Python to PATH».
3. Проверь: открой «Командную строку» (нажми `Win`, набери `cmd`, Enter) и введи:
   ```
   python --version
   ```
   Должна появиться версия, например `Python 3.11.5`.

### Шаг 2. Скачай этот скрипт
Скачай папку `uzbek-transcription` (файлы `transcribe.py`, `requirements.txt`).
Положи её, например, на Рабочий стол.

### Шаг 3. Установи ffmpeg (для чтения видео)
Самый простой способ — в командной строке:
```
winget install ffmpeg
```
Если `winget` не работает — скачай вручную с https://www.gyan.dev/ffmpeg/builds/
(файл `ffmpeg-release-essentials.zip`), распакуй и добавь папку `bin` в PATH.
Проверка:
```
ffmpeg -version
```

### Шаг 4. Получи бесплатный токен HuggingFace (для распознавания собеседников)
Это нужно, чтобы скрипт **различал, кто говорит**. Без токена он всё равно
сделает транскрибацию с таймкодами, но без имён спикеров.

1. Зарегистрируйся на https://huggingface.co (бесплатно).
2. Прими условия двух моделей (просто нажми «Agree» на страницах):
   - https://huggingface.co/pyannote/speaker-diarization-3.1
   - https://huggingface.co/pyannote/segmentation-3.0
3. Создай токен: https://huggingface.co/settings/tokens → «New token» →
   тип **Read** → скопируй строку вида `hf_xxxxxxxx`.

### Шаг 5. Установи библиотеки
В командной строке перейди в папку со скриптом и установи зависимости:
```
cd %USERPROFILE%\Desktop\uzbek-transcription
pip install -r requirements.txt
```
Установка большая (несколько ГБ), первый раз идёт долго — это нормально.

### Шаг 6. Запусти транскрибацию
Замени путь на путь к своему видео (перетащи файл в окно cmd, чтобы путь вставился сам):

```
python transcribe.py --input "C:\Users\ТВОЁ_ИМЯ\Downloads\Telegram Desktop\algo group.mp4" --hf-token hf_ТВОЙ_ТОКЕН
```

Первый запуск скачает узбекскую модель (~1.5 ГБ) — это разово.
Дальше пойдёт распознавание. Когда закончится — рядом с видео появятся
файлы `algo group.txt` и `algo group.srt`.

## Как вписать реальные имена собеседников

Есть два способа:

**Способ А (проще).** Открой готовый `.txt`, найди «Спикер 1», «Спикер 2» и
замени их на имена через «Найти и заменить» (в Блокноте или Word — `Ctrl+H`).

**Способ Б.** Если заранее знаешь, кто в каком порядке впервые заговорит,
передай имена сразу при запуске:
```
python transcribe.py --input "...\algo group.mp4" --hf-token hf_... --names "Азиз,Дилноза,Ведущий"
```

---

## Полезные параметры

| Параметр | Зачем |
|----------|-------|
| `--input` | путь к видео или аудио (обязательный) |
| `--hf-token` | токен HuggingFace для распознавания собеседников |
| `--num-speakers 4` | если точно знаешь число собеседников — укажи, будет точнее |
| `--names "Имя1,Имя2"` | подставить реальные имена вместо «Спикер N» |
| `--output "C:\...\итог"` | своё имя/папка для результатов |

## Переразбивка на ПОСЕКУНДНЫЕ таймкоды (`resegment.py`)

Если у тебя уже есть готовая транскрибация, где таймкод стоит большими блоками
(раз в ~30 секунд), а нужно разбить текст на короткие фразы — каждую со своим
таймкодом, используй `resegment.py`:

```
python resegment.py --input "algo_group__transkripsiya.txt" --output "algo_group__posekundno"
```

Скрипт:
- берёт реальное время начала каждого блока из исходного файла;
- делит текст внутри блока на отдельные фразы (по точкам, «?», «!»);
- рассчитывает таймкод каждой фразы пропорционально её длине между двумя
  соседними реальными метками (интерполяция);
- сохраняет `.txt` (по фразе на строку с меткой `ЧЧ:ММ:СС`) и `.srt`.

> Важно: начало каждого блока — точное время из транскрибации, а время фраз
> **внутри** блока — расчётное (оценка ±несколько секунд). Для точных
> посекундных меток каждого слова нужно заново прогнать видео через
> `transcribe.py` (там таймкоды берутся напрямую из аудио).

## Если что-то не работает

- **`ffmpeg не найден`** → вернись к шагу 3.
- **Ошибка про токен / диаризацию** → проверь шаг 4 (принял ли условия обеих моделей).
  Без токена скрипт всё равно выдаст транскрибацию, но без имён спикеров.
- **Очень медленно** → это нормально для процессора (CPU). С видеокартой NVIDIA
  будет в разы быстрее (torch сам её задействует).
- **Узбекский текст с ошибками** → у модели WER ~17%, часть слов может быть неточной;
  итог стоит вычитать вручную.
