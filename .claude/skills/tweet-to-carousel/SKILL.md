# tweet-to-carousel

Ты — контент-машина владелицы 4 Instagram-аккаунтов. Она кидает ссылку на твит — ты
выдаёшь готовый к публикации пакет под нужный аккаунт. Никаких лишних вопросов, если
всё однозначно.

## Шаг 0. Загрузи профили
Прочитай все файлы `accounts/*.md` (кроме `_TEMPLATE.md`). Каждый — это «скилл» аккаунта:
тема, голос, формат карусели, дизайн-токены, стиль прогрева. Держи их в голове.

## Шаг 1. Прочитай ссылку
Достань содержимое твита/треда через Firecrawl (`firecrawl_scrape`, formats: ['markdown']).
Если Firecrawl недоступен — `WebFetch`. Вытащи: основную мысль, факты, цифры, весь тред.

## Шаг 2. Выбери аккаунт
Сопоставь тему твита с нишами аккаунтов. Правила:
- Явно подходит одному → делай для него, коротко сообщи выбор.
- Подходит нескольким → сделай для КАЖДОГО подходящего свою версию (разный угол под нишу).
- Не подходит никому → скажи об этом и предложи ближайший аккаунт.
Пользователь может в сообщении указать аккаунт явно — тогда используй его.

## Шаг 3. Напиши карусель
По структуре из профиля аккаунта. Общие правила:
- **Обложка (slide 1):** сильный хук в голосе аккаунта. Не пересказывай твит дословно —
  переупакуй под аудиторию и нишу аккаунта.
- **Слайды сути:** 1 мысль = 1 слайд. Коротко, по делу, в тоне аккаунта.
- **Предпоследний:** вывод / инсайт.
- **Последний:** CTA из профиля.
- Соблюдай язык аккаунта и его стоп-темы. Ориентируйся на примеры «как надо» из профиля.

## Шаг 4. Собери JSON-спеку и отрендери
Сформируй spec.json: `account`, `theme` (из профиля: bg/fg/accent/handle/шрифты), `slides[]`.
Типы слайдов: `cover`, `point` (index/title/body), `quote`, `cta` (title/body/button).
Сохрани в `carousel/specs/<account>-<slug>.json`, затем:
```
node carousel/render.mjs carousel/specs/<account>-<slug>.json
```
PNG появятся в `carousel/output/<account>-<slug>/`. Покажи пользователю обложку через Read.

## Шаг 5. Подпись к посту
Напиши caption по профилю (длина, эмодзи, хэштеги). Первая строка — цепляющая.

## Шаг 6. Прогрев (сторис)
Напиши N сторис по логике прогрева из профиля (боль → интрига → польза → анонс → призыв).
Каждая сторис = 1–2 короткие фразы + подсказка визуала («селфи/текст на фоне/опрос»).

## Шаг 7. Отдай пакет
Выведи одним сообщением:
1. Какой аккаунт и почему.
2. Ссылку на папку с PNG-слайдами + показанную обложку.
3. Текст поста (готовый к копипасту).
4. Прогрев по сторис.
Если несколько аккаунтов — повтори блок для каждого.

## Параллельность (4 аккаунта)
Если задача — сделать под все 4 сразу (или ссылка подходит нескольким), генерируй версии
для каждого независимо. Можно распараллелить через субагентов (по аккаунту на агента),
но профили и рендер у каждого свои — не смешивай голоса и дизайн.

## Автопостинг
По умолчанию НЕ публикуй — отдавай пакет. Автопостинг подключается отдельно
(см. SETUP.md, раздел «Фаза 2»): Buffer/Publer API или Instagram Graph API.
